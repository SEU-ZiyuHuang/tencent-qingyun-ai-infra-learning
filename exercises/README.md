# C++ 代码实战题

这里存放需要独立完成的 C++ 功能模块题。题目会从单个函数逐步过渡到可以编译运行的小模块，再逐步接近推理工程中的数据结构和内存操作。

## 每道题的目录结构

```text
题目目录/
├── README.md          # 需求、接口、输入输出和测试样例
├── submission.cpp     # 你的提交版本
├── tests.cpp          # 测试代码（必要时提供）
└── notes.md           # 复盘、错误和优化记录
```

在你提交代码之前，`submission.cpp` 和 `notes.md` 可以暂时不存在。你完成代码后，把 `.cpp` 内容直接发给我，或者把文件放在对应目录中；我会先进行编译和测试，再整理上传。

## 验收标准

- 能够独立编译运行；
- 核心功能通过题目给出的测试样例；
- 能解释关键数据结构、参数传递和时间复杂度；
- 能指出至少一个边界条件；
- 代码格式和命名基本清晰。

## 提交流程

```text
阅读题目 → 独立写 submission.cpp → 编译/测试 → 反馈修改 → 复盘归档 → 提交 GitHub
```

不会把答案直接放在题目说明中。只有在你完成尝试并提交代码后，才会根据你的代码进行提示、讲解和修正。
