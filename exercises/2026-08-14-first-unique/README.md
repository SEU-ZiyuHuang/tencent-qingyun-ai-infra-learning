# 实战题 02：找出第一个只出现一次的数字

## 题目目标

继续使用 `unordered_map`，练习：

- 用 key-value 记录数字出现的次数；
- 使用 `find()` 和 `end()` 查询；
- 理解为什么需要先统计、再按原顺序查找；
- 分析平均时间复杂度和空间复杂度。

## 函数要求

实现：

```cpp
#include <vector>

int firstUniqueIndex(const std::vector<int>& nums);
```

要求：

- 返回数组中第一个只出现一次的数字的下标；
- 如果不存在只出现一次的数字，返回 `-1`；
- 不修改输入数组；
- 必须使用 `std::unordered_map`；
- 函数之外写 `main()`，至少完成 3 组测试。

“第一个”按照数组下标判断，不是按照数字大小判断。

## 测试样例

```cpp
nums = {4, 5, 1, 2, 0, 4}
期望结果：1
```

因为数字 `5` 只出现一次，并且它的下标是 `1`。

```cpp
nums = {1, 1, 2, 2}
期望结果：-1
```

```cpp
nums = {7}
期望结果：0
```

建议额外测试：

```cpp
nums = {2, 3, 2, 4, 3, 5}
期望结果：3
```

## 思考提示

建议分成两次遍历：

### 第一次遍历

建立：

```text
数字 → 出现次数
```

例如：

```text
{4, 5, 1, 2, 0, 4}

4 → 2
5 → 1
1 → 1
2 → 1
0 → 1
```

### 第二次遍历

按照原数组顺序查找第一个出现次数为 `1` 的数字。

这一步建议练习：

```cpp
auto it = frequency.find(nums[i]);

if (it != frequency.end())
{
    // 查看 it->second
}
```
