# 2026-08-14｜First Unique Index 复盘

## 验收结果

核心算法正确：第一次遍历统计出现次数，第二次按照原 vector 顺序寻找第一个出现次数为 1 的位置。

- `{4, 5, 1, 2, 0, 4}` → 索引 `1`
- `{1, 1, 2, 2}` → 无解
- `{7}` → 索引 `0`
- `{2, 3, 2, 4, 3, 5}` → 索引 `3`

用户已确认当前测试输出。

## 算法理解

两个循环是前后顺序执行的，不是嵌套执行，也不是递归。因此时间复杂度是：

`O(n) + O(n) = O(n)`

额外空间主要来自保存频次的 `unordered_map`，平均空间复杂度为 `O(n)`。

## const vector<int>&

- `const` 表示函数内部只能通过 `nums` 读取，不能修改元素或追加元素。
- `&` 表示 `nums` 是原 vector 的引用，不会复制整个容器。
- 两者结合后，函数既不会复制输入，也不会意外修改输入。

## int 与 size_type

`nums.size()` 返回的是 vector 的 `size_type`，通常是无符号的 `std::size_t`，不是 `int`。`int` 可以表示负数，但正数范围通常小于 `size_type`。

因此把 `size()` 强行放进 `int` 可能发生数据溢出；把 `int` 下标和 `size_type` 比较也可能产生 signed/unsigned comparison 警告。

本次重构将函数返回值、循环下标、调用方保存结果和输出函数参数统一为 `std::vector<int>::size_type`。

## 无解标记

有效下标范围是 `0` 到 `nums.size() - 1`，所以 `nums.size()` 永远不是有效下标，可以约定它表示无解。

这和返回 `-1` 的思路相同，但与无符号的 `size_type` 更匹配。`printResult()` 已经把这个标记转换为“没有唯一元素”。

空 vector 分支也已补充无解输出；后续应继续保留空输入、全重复输入等边界测试。

## 工程实践结论

`std::vector<int>::size_type` 类型最明确，但书写较长。工程中常见的简化方式包括 `std::size_t`、类型别名，以及在不需要下标时使用范围遍历。若接口需要明确表达可能无结果，后续还可以学习 `std::optional`。
