# 2026-08-14｜First Unique Index 复盘

## 验收结果

当前实现的核心算法正确，四组测试的结果应为：

- `{4, 5, 1, 2, 0, 4}` → `1`
- `{1, 1, 2, 2}` → `-1`
- `{7}` → `0`
- `{2, 3, 2, 4, 3, 5}` → `3`

## 算法理解

第一次遍历统计每个数字出现的次数，第二次按照原 `vector` 的顺序寻找第一个出现次数为 `1` 的位置，并返回下标。

两个循环是前后顺序执行的，不是嵌套执行，因此时间复杂度是：

`O(n) + O(n) = O(n)`

这里不是“递归”。递归指函数调用自己，是另一个概念。

额外空间主要来自保存频次的 `unordered_map`，空间复杂度为平均 `O(n)`。

## `int` 与 `nums.size()` 的类型

循环变量 `i` 声明为 `int`，而 `nums.size()` 返回的是 vector 的 `size_type`，通常是无符号的 `std::size_t`，不是 `int`。

因此比较两者时，严格编译选项可能给出 signed/unsigned comparison 警告。当前输入规模下不影响算法逻辑，之后单独学习索引类型时再规范化。

## 其他观察

- `count[nums[i]]++` 在第一次遇到数字时会先得到默认值 `0`，再增加到 `1`。
- 第二次遍历中，所有 `nums[j]` 都已经在第一次遍历中出现过，因此读取 `count[nums[j]]` 不会遇到未统计的数字。
- `printResult()` 对当前非空测试可以正常工作；如果以后加入空 vector 测试，还需要额外打印无解结果。
