# 2026-08-17｜const 引用、size_type 与索引接口

## 今日目标

理解 `const std::vector<int>&` 的只读与引用语义，理解 `vector::size()` 的返回类型，并把 First Unique Index 重构为类型一致的索引接口。

## 今天掌握的概念

1. `const` 限制的是函数内部通过参数名进行的写操作，不是把整个函数声明成 const。
2. `&` 表示引用，不复制原 vector；`const&` 同时实现只读和避免复制。
3. `size()` 返回 `vector` 的 `size_type`，它通常是无符号类型，不能简单当作 `int`。
4. 有效下标是 `0` 到 `size() - 1`，因此可以约定 `size()` 作为无解标记。
5. 类型一致不仅影响警告，也影响大规模数据下的正确性；把大下标塞进 `int` 可能溢出。
